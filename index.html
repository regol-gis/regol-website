Fast, single-file OpenStreetMap queries in Rust

regol is an independent, pure-Rust GeoDesk GOL 2.0 reader, spatial query engine, and OSM PBF compiler—built for country- and continent-scale lookups with no C, SQLite, or native GeoDesk dependencies.

Get started API reference crates.io

Rust 1.85+ · Safe by default (#![forbid(unsafe_code)] without mmap)

# Build a GOL 2.0 file from OpenStreetMap PBF
$ regol build region.osm.pbf region.gol

# Query cafés in a GeoJSON polygon as GeoJSONL
$ regol query region.gol 'na[amenity=cafe]' \
    --area district.geojson \
    -f geojsonl > cafes.geojsonl

# Export roads in a bounding box to CSV
$ regol query region.gol 'w[highway]' \
    --bbox=-0.14,51.49,-0.10,51.52 \
    -f csv --keys id,name,highway
use regol::{Library, Query, Result};

fn main() -> Result<()> {
    let library = Library::open("region.gol")?;
    let cafes = Query::parse("na[amenity=cafe]")?
        .prepare(&library)?;

    println!("Total cafés: {}", cafes.count()?);
    for feature in cafes.iter() {
        let feature = feature?;
        if let Some(name) = feature.tag("name")? {
            println!("{}: {}", feature.id(), name);
        }
    }
    Ok(())
}

Single-file GOL 2.0

Reorganizes .osm.pbf snapshots into zoom-pyramid tiles, tag categories, and Hilbert-ordered R-trees so queries read only overlapping branches.

100% pure Rust

Zero C toolchains, SQLite staging databases, or external GeoDesk runtimes. Enforces #![forbid(unsafe_code)] when mmap is not enabled.

CLI & embeddable crate

Ship regol inside Rust services or run regol-cli to build, inspect, verify CRC32C checksums, query, and export GIS and OSM formats.

Disk, RAM, or S3

Generic over positioned byte reads (Source): run on local disks, bounded caches, immutable memory maps, or custom HTTP/object-storage backends.

Pure-Rust PBF Compiler

Build and tune GOL 2.0 files directly from OSM PBF

regol build compiles raw or zlib-compressed .osm.pbf snapshots in parallel in memory and atomically publishes the finished .gol file—ready for local queries or remote range-read serving.

  • Presets for real workloads: --preset vector-tiles for S3 range reads and --preset compact for smaller metadata headers.
  • Layout tuning: control tile size (--target-tile-kib), even zoom steps (--even-zooms), border duplication, and per-tile R-tree fanout.
  • Embeddable: enable the optional build Cargo feature to compile GOLs straight from Rust via regol::build.

GOQL & Spatial Engine

Expressive queries, full OSM topology, and SI units

Prepare a GeoDesk Query Language (GOQL) selector once to resolve tag dictionary codes and category bitmasks, then reuse it across bounding boxes, spatial filters, parallel counts, and zero-allocation streaming scans.

  • Exact spatial predicates: Intersects, Within, Contains, CoveredBy, Touches, Overlaps, Crosses, Disjoint, and WithinDistance.
  • Full OSM relationships: combine FeatureSets with and, or, without, and traverse member_set, parent_set, and connected_to.
  • Typed spherical measurements: lengths, perimeters, distances, and areas returned as type-safe uom SI quantities.

Command-Line Tool

Inspect, verify, and export from a single binary

regol-cli bundles build, info, check, and query into one standalone binary. Queries memory-map immutable files, load the string dictionary on demand, and encode large exports in parallel while preserving query order.

count ids geojson geojsonl wkt csv xml pbf

Includes GeoJSON antimeridian splitting, polar cap closure, configurable coordinate precision, custom CSV columns, and --complete-relations for self-contained PBF extracts.

regol CLI workflow 
# Inspect metadata, indexed keys, and tile counts
$ regol info region.gol

# Verify CRC32C checksums, R-tree bounds, and links
$ regol check region.gol

# Extract a PBF slice for a bounding box
$ regol query region.gol 'w[highway]' \
    --bbox=-0.14,51.49,-0.10,51.52 \
    -f pbf > roads.osm.pbf

# Export building areas inside a GeoJSON polygon
$ regol query region.gol 'a[building]' \
    --area boundary.geojson \
    -f geojson > buildings.geojson

Pluggable I/O Architecture

Choose the storage backend that fits your runtime

Library<S> is generic over regol::source::Source. Combine any backend with DictionaryLoading::OnDemand to keep cold-start latency low for serverless functions and fast ID or count scans.

Backend Type / Constructor Best for
Retained pages Library::open(path) (PagedFile) Default safe file access; retains touched pages for repeated reads
Bounded cache source::CachedFile::open(path, bytes) Long-running services with a strict RAM budget
Read window source::WindowedFile::open(path) Low-memory streaming scans
Direct pread source::FileSource::open(path) Minimal wrapper around OS positioned reads
Memory-mapped source::MappedFile::open(path) mmap Maximum warm throughput on immutable local files
In-memory / custom &[u8], Vec<u8>, or impl Source Embedded fixtures, HTTP/S3 range-read caches, or custom storage layers

Quick Start

Up and running in seconds

Requires Rust 1.85 or later. Install the standalone command-line tool or add the regol library to your Cargo project.

Install the CLI

regol-cli

Provides the regol binary with build, info, check, and query.

Shell 
cargo install --locked regol-cli

regol build region.osm.pbf region.gol
regol query region.gol 'na[amenity=cafe]'
